# 星月启动器 0.7.7

本次更新增加内容来源和整合包安装方式，完善模组管理，并修复大量模组切换分类时的卡顿。

## 新增

- 接入 ATLauncher、FTB 整合包，以及 GitHub Releases 模组下载；支持 MC百科检索、原站入口和模组网站查看。
- 可选 AI 按模组名称查找项目；整合包模组下载失败后，可确认启用 AI 补下载并手动选择候选版本，下载结果仍须通过原清单校验。
- 支持将本地 `.mrpack` / `.zip` 整合包拖入主窗口安装，可一次加入多个文件。
- 正版账号显示皮肤头像；模组管理展示图标、简介、全部 / 已启用 / 已禁用分类和项目网站入口。

## 改进与修复

- 安装失败或取消后弹窗说明原因，清理本次新建的实例及临时文件，保留已有游戏、存档和原始整合包。
- 模组列表按滚动位置创建可见卡片，避免大量模组切换分类时阻塞动画。
- 修复筛选后组件宽度变化、分类切换动画中断、选项比例和占位图片圆角问题。
- 「删除版本」使用适配后的玻璃确认窗口；本项目操作仍将版本移入回收目录。

## 下载与更新

- Windows x64 单文件程序：`StarMoonLauncher-0.7.7-windows-x64.exe`，无需安装 Python。
- 0.7.6 用户可在「关于 → 检查启动器更新」获取新版。手动更新时先完全退出旧启动器，再在原便携目录运行新版，保留 `data/` 和游戏文件夹。
- `SHA256SUMS.txt` 提供程序与源码包的 SHA-256 校验值。
- CurseForge 与 AI 功能使用自行配置的 API；[内容来源说明](https://github.com/XYXM07/StarMoonLauncher/blob/v0.7.7/docs/CONTENT_SOURCES.md)列出了各来源的使用方式。
