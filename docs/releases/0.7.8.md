# 星月启动器 0.7.8

本次更新加入完整的模组、整合包和 Java 管理工具，并修复 Forge 环境下误报 Fabric 前置的问题。

## 新增功能

- **模组批量管理**：多选启用、禁用、删除、更新，支持锁定版本、忽略本次更新和按文件哈希识别来源。
- **整合包原地升级**：支持 Modrinth、CurseForge、ATLauncher 和 FTB，先预览文件差异与冲突，再选择处理方式；保留存档和截图，可从变更记录恢复。
- **依赖关系与修复**：树形显示前置、版本范围和冲突，可启用已禁用的前置或选择兼容候选安装；错误候选会回滚。
- **Java 管理中心**：检测和下载 Java，按全局或游戏版本设置运行时，清理未使用的托管 Java。
- **日志与问题报告中心**：日志搜索、级别筛选、实时刷新和脱敏报告 ZIP 导出。
- **下载与版本工具**：数据包、地图、Faithful 资源包来源，OptiFine / Cleanroom / LiteLoader 安装，自定义游戏窗口标题、截图查看及可选内容、格式和目录的整合包导出。
- **高级启动设置**：Vulkan（Mesa Zink）、DirectX 12（Mesa D3D12）与软件渲染选项，以及默认 JVM 参数、启动校验、Java 兼容检查和本地库适配开关。

## 修复与调整

- 依赖扫描先匹配当前加载器，多加载器 JAR 不再混用 Fabric / Forge 元数据；放错版本的模组显示加载器不匹配，真实缺失前置仍会提示。
- 账号管理统一位于「设置 → 账号管理」，修复自定义皮肤导致的账号页读取失败。
- 修复整合包失败清理与界面读取同时发生时刷新停止、失败弹窗不出现的问题。
- 优化紧凑窗口的安装布局，加载器重试时保持滚动位置与组件尺寸；完善 Fabric / NeoForge 镜像下载。
- 新增界面支持简体中文和 English。

## 下载与升级

- Windows x64 单文件程序：`StarMoonLauncher-0.7.8-windows-x64.exe`，无需安装 Python。
- 0.7.6 / 0.7.7 可通过「关于 → 检查启动器更新」升级。手动更新请先退出旧启动器，保留原目录中的 `data/` 与游戏文件夹。
- 提供当前源码 ZIP 与 `SHA256SUMS.txt`。
- 整合包原地升级仅适用于启动器管理的独立实例；外部 `.minecraft` 可先导出并导入。静态依赖检查不能保证发现所有运行期冲突。
- CurseForge 与 AI 功能仍使用自行配置的 API；Mesa 渲染器是否可用取决于所选 Java 架构和显卡驱动。

详见[管理功能](https://github.com/XYXM07/StarMoonLauncher/blob/v0.7.8/docs/MANAGEMENT.md)与[版本工具](https://github.com/XYXM07/StarMoonLauncher/blob/v0.7.8/docs/INSTANCE_FEATURES.md)。
