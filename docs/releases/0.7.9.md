# 星月启动器 0.7.9

本次更新加入服务器管理和默认 AI 模组依赖检查，正式版内置 CurseForge 接入，并修复搜索结果出现时的横向尺寸变化。

## 新增与改进

- **服务器列表**：在「更多 → 服务器管理」收藏、编辑和搜索服务器，查询人数、版本、简介和延迟，选择游戏版本与当前账号直接加入；支持 IPv6、自定义端口和域名 SRV 查询。
- **本地开服**：导入已有服务端 JAR 或 Forge/NeoForge 参数文件，下载官方原版服务端，管理 Java、内存及常用配置；支持实时控制台、命令发送、正常停止与强制结束。首次需主动同意 EULA。
- **运行管理**：本地服务端显示在「正在运行」，关闭主窗口后可继续在后台运行；运行中暂停更新安装与 Java 清理。移除管理记录会保留服务端文件和存档。
- **AI 依赖检查**：默认使用已配置的大模型分析，可切换到本地检查；大量模组分批处理，保留相关的全量前置和禁用项信息，显示各批结果及未完成状态。
- **CurseForge 内置接入**：官方 EXE 无需玩家填写 API Key 即可搜索、下载和导入整合包；设置中的自定义密钥仍优先。源码包不包含发布者密钥，作者禁止第三方下载的文件仍需手动处理。

## 修复与界面

- 「服务器列表 / 本地开服」使用一体式玻璃切换组件，带选中滑块与平滑动画。
- 修复 CurseForge 搜索加载、少量结果或空结果时组件向右扩宽；长标题和作者信息不会撑开结果区。
- 修复 AI 模组检查因输入截断而无法判断全部模组的问题；批次失败或元数据异常时明确提示检查不完整。
- 完善新增界面的简体中文与 English 支持。

## 下载与升级

- Windows x64 单文件程序：`StarMoonLauncher-0.7.9-windows-x64.exe`，无需安装 Python。
- 已有版本可通过「关于 → 检查启动器更新」升级。手动更新请先完全退出旧启动器，保留原目录的 `data/` 和游戏文件夹。
- 同时提供当前源码 ZIP 与 `SHA256SUMS.txt`。
- 本地服务端管理只控制当前启动器启动的进程，自动下载目前限原版；公网连接仍需自行配置网络。AI 检查使用玩家配置的模型接口，不能保证发现所有运行期冲突。

说明：[服务器管理](https://github.com/XYXM07/StarMoonLauncher/blob/v0.7.9/docs/SERVERS.md) · [管理工具](https://github.com/XYXM07/StarMoonLauncher/blob/v0.7.9/docs/MANAGEMENT.md)。
